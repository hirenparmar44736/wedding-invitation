# Hiren ♥ Ashlesha — Premium Digital Wedding Invitation

A digital wedding invitation for **Hiren Parmar & Ashlesha Modhvania**, featuring:
- **Opening Invitation Curtain/Panels:** 3D sage-green gates with embossed botanical motifs, gold antique seal, and touch/tap-to-open interaction.
- **Main Wedding Invitation:** Champagne draped curtains, vintage borders, parents' blessings, and bilingual Gujarati/English text.
- **Interactive Scratch to Reveal:** Canvas-based scratch card that works across mobile touch and desktop cursors, revealing the romantic blessing with particle confetti.
- **Save the Date:** Generates and downloads a real `.ics` calendar invitation file for 24 & 25 February 2027.
- **Live Countdown:** Real-time countdown timer targeting 24 February 2027 IST.
- **Wedding Timeline:** Vertical editorial itinerary for Day 1 (Ganesh Pujan, Jamanvar, Haldi, Garba) and Day 2 (Shadi / Wedding Ceremony).
- **Venue & Directions:** Direct navigation integration to the exact destination in Umrala, Gujarat.
- **Dress Code:** Illustrated traditional motifs for Women (Saree / Lehenga) and Men (Kurta / Sherwani).
- **Final Blessing:** Warm closing invitation note with royal seal accents.
- **Centralized Config:** `src/config/wedding.ts` for editing event timings and details.

## Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

## Deployment to Vercel

```bash
npx vercel --prod
```
